# 🍳 ChefSync — Multi-AI Culinary Engine

A web-based multi-AI culinary council that generates smart, student-friendly recipes from available pantry ingredients.

## 🚀 Overview
ChefSync orchestrates a real-time AI consensus between **Groq**, **Gemini**, **Claude**, and the **Serper API** search engine to help students and bachelors cook easy, low-utensil meals with whatever ingredients they have on hand.

## 🛠️ Tech Stack & Architecture
- **Frontend:** Vanilla HTML5, CSS3, JavaScript (Hosted on GitHub Pages)
- **Backend:** Node.js, Express (Hosted on Render)
- **AI Council Stack:**
  - **Groq Engine (Llama 3.3):** Rapid drafting & lightweight helper (*Mini Kevaris*)
  - **Gemini Engine (Gemini 2.0):** Ingredient safety, optimization & substitutions
  - **Claude Engine (Claude 3.5 Sonnet):** Chief AI Director for consensus & final recipe synthesis
  - **Serper API:** Real-time culinary search verification

## ⚙️ Environment Variables
To run the server, set the following environment variables on your host or in a local `.env` file:
- `GROQ_API_KEY`
- `GEMINI_API_KEY`
- `CLAUDE_API_KEY`
- `SERPER_API_KEY`
- `PORT` *(Default: 3000)*
